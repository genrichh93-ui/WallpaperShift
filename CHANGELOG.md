# Changelog

## [1.0.0] - 2026-10-10

First stable release of **WallpaperShift**, renamed from the tested **WallShift v2 preview**.

- Three wallpaper modes: original wallpaper + solid color, two local images, and a local image folder.
- Optional interval and day/night automation.
- Double-click background gesture and two keyboard shortcuts.
- OLED black override, reversible without losing the active selection.
- GNOME Shell 51 support with GTK4/libadwaita preferences.
- Original wallpaper settings backup and restoration.

The extension UUID and settings schema are **unchanged** from the v2 preview for upgrade compatibility.
